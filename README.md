# 纸间 · Android 安装包

此仓库用于发布 APK、更新信息和使用说明。应用源码不在此公开仓库发布。

从 [Releases](https://github.com/junnhwan/wanjune-notes/releases/latest) 下载正式 `release.apk` 并按系统提示安装。固定包名 `app.zhijian.notes`，支持 Android 7 及以上；所有运行资源包含在 APK，无需账号或电脑服务器，可断网使用。

首次使用前，在原浏览器“数据与备份”导出完整 JSON，再传到手机从备份恢复。两端数据各自独立，不会自动共享。替换恢复前另存当前备份；接受 v1/v2/v3。

笔记、图片、文件夹、双面卡片、回收站和设置本机保存。请定期将完整 JSON 备份保存到应用外的位置，并保留两份。卸载或清除数据会删除私有内容。

设置页可检查更新、查看说明、下载和校验 APK，然后交给系统安装。首次需要允许纸间安装未知应用；授权返回后再次点击系统安装。可以取消下载或安装，发布源不可用时仍可本地编辑。后续版本用同包名、持续签名覆盖升级，**不要先卸载**。

HTML 导出内嵌图片，电脑浏览器断网可读；TXT/剪贴板与系统分享可用。PDF 在系统打印中选择“保存为 PDF”。打开系统窗口不代表操作完成，取消不会发送内容。

目前为 Android 安装验收版。Android 模拟器已验证核心图文/卡片/目录/回收站、备份往返、系统文件/分享/PDF、进程恢复和保存失败重试。目标 vivo Y600 Pro（V2561A、Android 16、OriginOS 6）的中文输入法、后台限制和厂商安装流程仍待真机验收，未宣称已通过。

保存失败时保留草稿，先重试或导出备份；只有显示“已保存到本机”才代表内容已持久化。
